# Public Website Procurement Preflight

A browser-private ten-decision check for public-service teams preparing a website solicitation or evaluating whether their brief is ready for vendor comparison.

The tool stores and sends nothing. It is grounded in current official accessibility acquisition guidance and routes teams that need implementation help to Evolved Designs.

[Use the live preflight](https://evolved-designs.github.io/public-website-procurement-preflight/)
